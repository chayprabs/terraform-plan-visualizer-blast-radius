# Security Policy

## Reporting a vulnerability

If you discover a security issue, please report it responsibly via a private
GitHub security advisory on the repository, or open a minimal reproduction
issue without posting secrets or production plan data.

## Scope

This project is a client-side Terraform plan review tool. Sensitive plan JSON
should remain in your browser. Do not attach real infrastructure plans to public
issues.

## Supported versions

Security fixes are applied to the `main` branch. Deploy the latest commit from
`main` for production use.
