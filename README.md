## Authos

Browser-first developer tools, starting with the Terraform Plan Visualizer.

## Stack

- Next.js App Router with TypeScript
- Tailwind CSS
- ESLint and Prettier
- Vitest with Testing Library
- Playwright

## Scripts

```bash
pnpm dev
pnpm lint
pnpm typecheck
pnpm test
pnpm e2e
pnpm build
```

The main tool route lives at `/tools/terraform-plan-visualizer`.

The initial experience is local-first by default:

- Runs locally in the browser
- No authentication
- No backend API for the core tool
